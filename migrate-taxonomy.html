Category Schema Migration

This utility converts existing resource documents from comma-delimited category strings to Firestore arrays.

Run this before deploying the hard-cutover app/admin changes. This page should not remain publicly hosted after the migration is complete.
  1. Start a local web server for this repo.
  2. Open this page and log in with the admin Firebase account.
  3. Click Preview Migration.
  4. Review the log.
  5. Click Run Migration.
  6. Deploy the updated app only after the migration succeeds.
